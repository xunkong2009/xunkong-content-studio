# 选段与动作方案

优先选“画面能解释的变化”：商品角色改变、成本累积、购买/传播循环、数量或尺度差异、结构拆解、前后反转、机制因果。观点或事实本身适合主播、真实素材或静态图时不要硬做动效。

## MotionSelectionPlan

每段保留以下内容：

| 字段 | 要回答的问题 |
| --- | --- |
| beat_id / 原文 | 来自哪个已确认节拍？原文不改写 |
| viewerQuestion | 观众看完应能回答哪个具体问题？ |
| visualModel | 用什么主体、空间或图表承载解释？ |
| 状态变化 | 主体起初在哪里/是什么，如何变化，最后是什么？ |
| 触发短语 / 焦点 | 哪句口播触发哪次变化？此时应看哪里？ |
| 覆盖方式 / 时长依据 | 覆盖原文全部还是局部插片？实际录音还是估算？ |
| layoutMode / 页面文字 | 构图怎样服务变化？哪些文字必需？ |
| 素材方式（需要时） | 哪些复用、哪些生成、哪些用代码？动作需要什么姿态/视角/分层？ |
| 声音用途 | 哪个关键动作需要声音？何时触发，或为什么保持安静？ |
| 确认状态 | 待确认、用户提供或已获直接制作授权 |

`full-excerpt` 覆盖整段口播，时长必须足够；`illustrative-insert` 对应原文内明确的连续短语，记录 `anchorText`，不声称覆盖整段。没有录音时先估算，交付时说明尚未按真人口播同步；不能把长段原文塞进默认 6–12 秒。

## 从内容到模型

- 角色变化：让同一个商品从附赠区域移到独立货架，再出现定价/活动身份。
- 成本累积：先建立单件成本，再重复成批并汇总数量；假设须标注，重复图形不能冒充真实样本。
- 消费循环：一个行动沿路径走完并回到起点，显示回访/反馈；不要仅画闭环箭头。
- 双重动机：用同一对象分别落入两种解释框架，比较参照保持一致。
- 数据证据：先建立单位、基线和范围，再显现变化并标记关键点；无数据不得画装饰性增长曲线。
- 复杂结构：总览→聚焦一处→展示局部动作→返回总览，保持对象颜色和位置线索。

这些是启发，不是题材模板。并列清单、简单对比和一句结论仍可用克制的入场，只要信息顺序、重点和阅读时间明确。整批应根据不同问题选择模型，避免用同一模型机械替换文案。

## 九类模板与交接
按 nine-templates.md 选择 templateId、presentation 和主题，记录对应 beat_id、素材需求。先规划后录制，粗剪确定后标注实际触发时间并正式制作。浮层适配固定机位，可遮肩手，不遮脸；没有真人视频时不能声称已验证脸部避让。
