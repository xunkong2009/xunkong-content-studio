# 动效讲解逻辑

## 设计顺序

1. 写观看问题：不用“提升高级感”，写“为什么原本附赠的商品能单独卖”。
2. 找可记住的主体：商品、消费者、货架、单位成本、坐标轴等。先建立身份，再推演。
3. 定义能看见的变化：主体脱离原位置、进入新位置、数量累积、对象合并、比例改变、路径回到起点等。说明动作承载的含义。
4. 排信息顺序：背景/参照先建立，证据与变化跟随口播，结果后出现。把长句拆成视觉动作，不把所有文字同时贴上。
5. 调注意力：当前讲的主体提高对比或放大，其余淡下；运动目标、标签和高亮指向同一对象。不要一边缩放镜头一边让多人/多组数字争抢焦点。
6. 留停顿：运动用于解释，静止用于理解。按文字量、复杂度和真实语速分配停留，先保证观众能读完，不设统一毫秒模板。
7. 定接口：首尾稳定画面接主播/素材。结尾可以停在有意义的结果，避免自动淡成空白。

## 常用调度

| 调度 | 适合解决的问题 | 实现注意 |
| --- | --- | --- |
| 同一主体迁移 | 角色、位置、渠道变化 | 保留颜色/形状身份，轨迹起终点有含义 |
| 拆解/合并 | 构成、分工、整合 | 明确谁成为谁，不能只用交叉淡入冒充关系 |
| 单位→重复→总量 | 规模、复利、成本累积 | 总数/单位/假设可查，缩略图形标示为示意 |
| 共同参照对比 | 价格、规模、效率 | 同量纲同刻度，换单位时明确切换，不以面积误导 |
| 总览→局部→返回 | 复杂系统 | 保留定位线索；缩放节制，不把3D旋转当默认 |
| 行动→反馈→再次行动 | 传播、复购 | 可见主体沿路径完成一轮，循环次数不伪装统计 |
| 铺垫→重点揭示 | 反差与判断 | 关键结果跟随对应短语；开场标题不提前剧透 |

弱化的旧图仍可能是有效上下文，不必整屏清空。无关旧标题和与新内容冲突的图形应退出；共享主体继续推演，镜头或构图围绕它变化。

## 动作节奏记录

新清单 `motionDesign`：

- `viewerQuestion`、`visualModel`、`layoutMode`。
- `coverageMode`: `full-excerpt` 或 `illustrative-insert`；`anchorText` 是原文中的连续短语。
- `timingSource`: `estimated` 或 `narration`。后者还填写 `timingEvidence` 指向真实时间轴/录音标注，不能凭阅读感觉填。
- `beats`: 按时间顺序记录 `triggerText`、`action`、`focus`、`startFrame`、`endFrame`、`holdEndFrame`。触发短语须出自锚点原文；动作和停留不越出片长。新主要动作不抢占上一阅读停留。
- 一项 beat 是一次解释或焦点变化，不是每个装饰元素。微小辅助动作可以同步，重点动作之间有连续性。

实现时把这些关键时刻同步到组件和审片帧。清单不会自动验证语义、实际同步或美感，必须检查正常速度的视频。若要修改节奏，同时更新设计计划和审片帧。

## 参考视频研究

抽看多条同类视频：先扫描全片构图，再对关键段落连续抽帧或播放。记录具体时间和实际可见动作，不把几张图当成完整听审。区分：

- 可迁移的讲解方法：稳定主体、递进揭示、聚焦、停顿、回到共同参照。
- 当前用户适用的表达：商业/品牌/消费，米白黑红或深蓝金，默认竖屏插片或主播浮层，明确要求时制作横屏，可融入产品形态和少量幽默隐喻。
- 需按任务重选的外观：横屏总图密度、Logo数量、背景明暗、空间透视、解释时长。参考出现这些元素不代表默认照搬，也不代表禁用；由当前叙事、画幅和已确认风格决定。

有既往作品时同时比较实际成片与源代码：哪些动作真的传达变化，哪些只是在入场。保留有效的数据可视化与清晰文字，针对缺少因果或动作的片段改进。参考作品商业事实不自动成为当前脚本证据。

## 把原则落实到镜头

需要改进画面表现时读取 `shot-craft.md`，重点检查答案与问题对应、首帧信息量、对象迁移终点、数字合并槽位及焦点交接。已有规则正确而作品未做到时，修具体动作和验收点，不重复堆抽象原则。

## 交付前的三个问题

主体与机制类检查拿掉大部分文字后是否能看出变化；关键词/观点类检查强调对象、阅读顺序和停留；数据类检查单位、基线及最终值；关系类检查连线含义。各类均检查运动是否帮助理解、停留是否足够，不要求所有模板都有物体迁移或因果推演。
