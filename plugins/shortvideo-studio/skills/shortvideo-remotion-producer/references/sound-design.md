# 动效声音设计

横屏与竖屏均根据内容、语气和动作主动评估短音效是否帮助理解；有意义才加，不需要每次要求用户另行授权。用户明确无声时优先。目标是像参考博主那样让声音和讲解动作配合，具体音色、密度与商业内容的语气相称，不直接复制或截取参考视频音轨。

## 适合加在哪里

| 画面任务 | 声音用途 | 常见选择 |
| --- | --- | --- |
| 主体迁移、总图聚焦 | 提示注意力正在转移 | 轻短 whoosh，跟随运动方向/速度 |
| 商品/节点落位、完成合并 | 明确动作落点 | 轻 pop、click、柔和碰触音 |
| 重要数据、结论揭示 | 标出解释的重点 | 克制的短提示音，落在揭示瞬间 |
| 数量累积、循环反馈 | 让过程有节奏或确认回访 | 少量节拍/短触音；不用每帧计数都响 |
| 内容本身有幽默反差 | 辅助一个真正的包袱 | 偶尔短喜剧音；商业严肃判断不强加搞笑 |

安静也是声音设计的一部分。先选择少数最有价值的提示点；小幅入场、背景对象和阅读停留通常无声。不要给所有标题、标签、数字配同一个叮声，不连续铺满 whoosh，也不为了热闹增加梗音、人声或背景音乐。

## 声音与口播

- 音效通常约0.1–0.6秒，需要表达完整动作时再适当延长；不设每段固定次数。
- 移动音跟运动、落位音跟动作落点、揭示音跟内容出现。剧情/反差需要时可以刻意错开，但说明理由。
- 根据声源已有响度独立调整音效，不给所有素材固定套0.12–0.30等线性增益。低电平stem再次衰减会听不见；需要时提高音效而保持口播增益。以实际混听判断可辨认程度，结合局部RMS、峰值和余量检查，避免高频刺耳及低频重击压住口播。
- 接近口播关键字时优先减量、错峰或取消音效；有录音才实际混听。未提供录音时只检查音效与画面同步，说明真人混音仍待复核。
- 音效切入切出做短淡变，留干净尾音，不在片尾留下长尾或突然截断。多声同时出现要检查叠加峰值，不靠统一提高音量解决存在感。

## 素材与来源

优先用户/项目已有合规音效，或本项目程序合成的简单提示、碰触、噪声掠过音。自行寻找时核实可用于当前商业用途的许可，下载到项目内并登记来源；来源不明的影视、歌曲、人声梗不作为默认素材。读取当前可用的 Remotion 声音规范，可借鉴其音色类别；公开可访问的音效 URL 不自动等于已核实商用许可。

## 清单和工程

每段 `audio` 可为：

```json
{
  "mode": "sfx",
  "events": [
    {
      "src": "sfx/soft-pop.wav",
      "from": 120,
      "durationInFrames": 9,
      "volume": 0.18,
      "purpose": "小样在独立货架落位时给予轻提示",
      "source": "本项目程序合成"
    }
  ]
}
```

`src` 相对项目 `public/`；`from` 与时长单位为帧，和同一帧率下的视觉时间轴一致；`source` 记录来源/许可依据。`mode: silent` 时 events为空。未填写audio的旧清单仍按无声处理。

模板的 `scripts/audio-render.mjs` 在画面导出后，把 events 混入独立音轨；使用本机 FFmpeg（或 FFMPEG_BINARY 指定的路径），不添加配音或背景音乐。两条渲染入口都使用同一混音逻辑，先导出纯画面，再按模式输出无声或 AAC 音效（WebM 使用 Opus）。Studio不播放这条后混音轨，应看/听 `preview/motion/index.html`。

需要更复杂的实时声音预览或音量自动避让时，可按当前安装版本使用 Remotion Audio 组件，但应选择单一声音渲染入口，避免组件音轨和后混音重复叠加。

## 验证与交付

以正常速度试听，检查触发、密度、刺耳、突变、尾音和口播关系；有口播才混听，不把频谱/峰值检查称为听审。带音效的交付说明声音来源和试听状态；若没有实际试听，明确记录。媒体检查按每段模式要求音轨存在或缺席，不能一律拒绝音轨，也不能接受与设计无关的意外音轨。用户或剪辑需要时再提供纯画面版，不默认多导出一套。

## 交给剪辑
有音效的片段由后混音程序同时输出同名 .sfx.wav，作为纯音效 stem；交接表指明其在粗剪上的 start/end。剪辑默认排除视频内声音，只明确插入该 stem，避免重复混入。人声锁定指人声源、入出点与增益保持，最终混音允许新增动作声；无音效时继续复制并核对整个音轨哈希。

## 文字、导出与可听性

声音设计覆盖重点文字的进入和金黄词落定，不只照顾图形动画；行走/跌落/承接等过程可对应脚步、掠过和碰触，不机械每字发声。交接标明音效是否已混入、stem是否已带增益，避免重复或二次无意衰减。

实际成片中能辨认才算满足可听性目标，文件存在、峰值或相关性不能证明听感。按实际口播上下文提供输出试听片段；没有可靠听审则记录待试听。预览页增加有声播放入口，自动静音时显著提示开启声音。修正某版过轻时的增幅与事件数量只作案例，不设全项目默认值。
