# 动效剪辑交接

默认竖屏，明确要求横屏才制作横屏；沿用确定后的粗剪。核对共同 beat_id、base_video 与 base_sha256、实际 start/end 和 trigger_times，估时不可直接用于插入。优先修改动效适应自然人声。

- fullscreen：inserts 覆盖画面，不保留素材音轨。
- overlay：overlays 叠加透明 PNG/MOV/WebM，检查真实 alpha；原主播位置保持，浮层可遮肩手，不碰脸及运动余量，不压字幕。全画布透明素材用 x=y=0、width/height 为基准尺寸；局部素材给明确矩形。
- 固定角度无需主播让位。根据原片确定 face_regions，静态包围盒覆盖整段头部范围；头部移动大时按区间记录。程序检查声明的矩形，实际像素和中间动作仍须观看验证。
- 纯音效WAV：只通过sfx显式混入一次，原始素材声音仍忽略。默认gain=1，允许独立提高或降低音效，先核实stem内是否已带增益；人声增益固定1。先预检线性叠加峰值，潜在削波时调整音效，不用混音末端限幅改变人声；还须检查输出AAC峰值与实际听感。

material-plan.json 扩展见 commands.md。无音效保持整轨哈希；混音报告保留基准路径、哈希、所有声音事件，人声源与时间不改，最终波形因新增音效会改变。该报告不证明实际听审已通过。字幕以最终混音版本为基准。

普通字幕不要求始终出现。读取`final-composite.md`，由重点文字窗口提供suppress或reposition策略，字幕不能压住其最终位置或动画路径。
