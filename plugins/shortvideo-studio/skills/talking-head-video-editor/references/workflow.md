# 编辑决策与检查

## 环境

优先查找现有 FFmpeg、FFprobe、Python；字幕需要 FFmpeg 的 libass。`editor.py` 接受 `--ffmpeg`、`--ffprobe`，也支持 FFMPEG、FFPROBE 环境变量，不依赖某次任务的临时路径。默认 CPU 编码；硬件编码是可选项，受本机能力和运行权限限制，失败不得悄悄降低质量或绕过权限。

转写脚本需要 faster-whisper；字幕字体检查需要 fonttools 和 Pillow。先检查现有环境，必要时在用户批准后安装独立环境和模型，不自动运行安装命令。模型使用本地目录即可离线工作。Mac 字体通常位于 `~/Library/Fonts`、`/Library/Fonts`；查找 Alibaba/PuHui，不随 Skill 打包用户字体或视频。

## 第一阶段：粗剪

1. 提取/读取音频，生成带词级时间的转写。保留原始转写，另做脚本对应表。标出重录、口误、重复和长停顿候选，不用 VAD 直接决定最终剪口。发现单个词时间异常长、一个词跨越长静音、或停顿后重新起句，视为需局部核对的信号。
2. 对候选重录的前后两遍分别截取足够上下文、独立转写并核对声音。局部转写可关闭 VAD；提示词只给专有名词，不填入预期完整句子诱导识别。原始两段都含同一短语时，不能因整段 ASR 自动合并而同时保留。例如“因此，日本很早就有……[停顿] 日本很早就有月见乌冬”应保留一次完整短语，不能只删中间静音。刻意强调重复则保留。
3. 第一轮去掉错误重录与长等待，选择完整且自然的一遍，保护字头字尾。相邻重复单字需辨别停顿、词边界和完整短语，例如删“边边”不能连带切掉前句“现在”的“在”。尽量整短语换用一遍；必须词内或词间拼接时做额外复核。
4. 第二轮按下表处理节奏。独立检查句内停顿、原片片段前后的等待，以及被保留长片段内部的卡顿；不要只检查第一轮已有剪口。保留少量气口只是避免伤字时的临时选择，不是允许所有边缘空白留到成片。
5. 以原片秒数写 keep 数组，保留原因；渲染会按目标帧率量化并输出真实映射。弱字尾和爆破音结合波形、短音频回放定位。低能量既可能是气口，也可能是辅音或字尾，不能按音量单独删；不统一给所有剪口加长或缩短相同毫秒。
6. 导出后生成剪口审听包，逐处比较原片左段、原片右段、实际导出连接点，检查残留重复、缺字、语气连续性、口型与爆音。几毫秒淡入淡出只用于避免爆音，不应用长交叉淡化吞字。对比发现的问题修正后重新检查受影响连接点。
7. 清单至少记录：成片时间、原片前后时间、对应词句、停顿类型、删除/保留理由、重复核对结果、实际听审状态、未解决问题。技术校验、ASR 辅助复核与实际听审分别记录，不把任何自动结果写作人工通过。无法可靠听审时输出待试听版本及具体位置，不宣称重录全部清干净。
8. 交付无字幕粗剪；保存用户确认的文件路径及 SHA256。下一阶段以该版本为基准。

| 类型 | 编辑判断 |
| --- | --- |
| 同一句内：主谓、年份与事件、数字与单位、列举项目 | 优先连贯，去掉重启后的犹豫、残留等待；不能为了快而吞连读字或标点所需的小停顿 |
| 两个完整句子之间 | 留自然呼吸，不把每句话挤在一起 |
| 原因编号、转折、提问、结论 | 留出层次，结合整段语气决定停顿，而非照固定时长处理 |
| 片头、片段开头、片尾 | 检查准备动作和等待，字头字尾完整之外不额外保留无意义空白 |

## 用户修正版对比（仅在用户提供时）

把修正版与上一版声音对齐，区分删停顿、去重复、恢复误剪、替换录制遍次和变速；有变速或处理音效时不能强行按固定偏移对齐。记录匹配置信度与近似误差，结合原片检查具体词句。用户剪掉的内容不自动等于静音，导出帧率变化也不等于语速变化。

只总结得到证据支持的偏好，不把单次删除的毫秒数、剪口数、总时长或帧率写为通用目标。用户要求比较时不改视频；用户明确要求更新 Skill 时才更新 Skill，不顺带改长期记忆。

## 第二阶段：素材

读取素材目录，生成文件清单、时长、尺寸及缩略图。实际看图和关键帧，不只看文件名。给每个候选记录对应口播、入出点、选择理由。

素材在粗剪时间轴上覆盖画面，不改变口播时长。图片/信息页默认完整容纳；横屏实拍可留边，裁切需确认不会丢主体。不要为填满竖屏把图表文字裁掉。视频不足时换片段或保留主播；如确有编辑理由，可在计划中明确 source_span 变速，检查动作和动效数字的可读时长，不隐式循环。

开头观点、原因转场和结尾问题通常值得保留主播，具体遵循用户参考片。字幕安全区要结合所用素材检查，不能认为固定底部位置永远不遮挡。

## 第三阶段：字幕

在最终采用的成片上重新转写，或使用经过验证的最新时间映射。旧版粗剪字幕不可直接套在修正过的时间轴上。

用脚本纠正品牌、数字、同音词和繁简，不补写未说出的句子。生成 cues JSON 后按实际听感校准。自动文本对齐的替换和插值必须标记复核；不要把大段错配插值当作同步完成。中文每条通常 10–18 字，语义优先，避免闪现和跨说话停顿。

用字体文件读取真实 family 名称，检查字符覆盖和像素宽度。ASS 字号受字体 metrics 影响，以实际输出为准；1080×1920 可从 60 开始，左右各留 45 像素，再审片调整。文字可上移、分行，不能只无限缩字号。用最终渲染日志确认 fontselect，不能只凭文件名声称使用了指定字体。

## 项目状态建议

记录 `source`、`roughcut_confirmed`、`locked_audio_base`、`current_video`、`stage`、`font_file`、各输入 SHA256 和用户确认摘要。版本修正只改变请求范围。保存计划及软件日志，不把用户资料写入 Skill 或长期记忆。

## 动效叠加与声音
按 motion-handoff.md 对齐粗剪上的词句和时间。使用 overlays 叠加透明片，inserts 处理全屏插片，允许同时存在且层级明确。浮层可覆盖肩手，只保护脸及运动余量和字幕；已知固定机位区域可复用，抽查全段头部活动。动作和阅读停留必须保留；优先修改动效而不是拉伸人声。无音效复制基准音轨，有音效则独立 sfx 另轨混入并保存人声哈希和参数；字幕复制最终混音。

两个外部素材之间避免闪回不到一秒的主播；可直接连接素材，或保留完整自然的主播表达，通常尽量约2秒以上，按语义和实际节奏判断。

## 已确认样式下的局部返工

执行`final-composite.md`。普通字幕优先胸前偏下；重复重点文字窗口隐藏，补充句移至留白。保留无旧字幕母版，使用`captions --layout`安排默认位置、图解位置和隐藏帧窗口，输出实际可见SRT与ASS。修字幕位置不重做ASR、不改既定词句和时间；隐藏或边界切分必须可追踪。

macOS使用实际字体内部PostScript名称和绝对fontsdir，检查最终日志的fontselect及缺字。CoreText访问失败不能静默换成Helvetica；使用允许的字体服务权限后重试，或如实说明未完成。
