## 分享版个人配置

用户当轮提供的材料和要求优先。需要语料库、主播照片或本地字体时，可读取当前项目的 `.xunkong-studio/config.json`（如存在）；相对文件路径以当前项目为基准。配置示例见插件根目录 `config.example.json`，不要改写安装目录。

未配置语料库时使用随包风格规则继续写作；未配置真人参考照片时可先交付提示词或无人像方案。需要复现某个真人且缺少参考时，向当前用户索取参考，不使用发布者的身份。配置文件中不存储 API Key、密码或账号 Cookie。

# 口播视频剪辑

把用户录制的口播分阶段做成成品。使用本地媒体工具，不依赖 ChatCut。判断内容和剪口由你负责，附带程序执行确定的时间轴；不要把自动识别结果当作已经审过的剪辑决策。

## 开始与阶段选择

先确认当前请求属于粗剪、素材剪辑、字幕或局部修正；只推进请求的阶段。检查实际文件、视频旋转、分辨率、帧率、声音和现有交付版本。若存在多个版本，从当前用户确认记录和项目记录找出基准，不能仅凭修改时间选文件。

首次项目读取 [references/workflow.md](references/workflow.md)。合成精剪、字幕和声音返工前读取 [references/final-composite.md](references/final-composite.md)，执行透明重点文字、胸前普通字幕、按动效窗口避让及独立音效混音。使用程序时读取 [references/commands.md](references/commands.md)，先运行 `scripts/editor.py --help`。把输入、脚本、确认记录、计划、字幕、检查结果放在项目输出目录，不放进 Skill。

## 固定约定

- 原文件不覆盖，每次修正输出新版本；保存原片到粗剪、粗剪到成片的时间映射。
- 脚本辅助去重和纠错，以实际口播为准。不能通过删字把口播改成未说过的意思。
- 整段 ASR 可能自动省略重复词句；识别文本只出现一遍，不代表录音只说了一遍。疑似重录的前后两遍须分别核对，再决定留哪一遍。
- 节奏按语义处理：句内保持连续，句间保留呼吸，转场保留层次。保护字头字尾不等于保留整段前后气口；也不按固定秒数或目标总时长机械压缩。
- 默认先交付粗剪，等待用户确认后再配素材。用户明确授权完整流程时可直接继续，仍须审查剪口。
- 确认后的粗剪人声源、时间与增益锁定；默认只换画面且排除素材原声，整个音轨复制并校验哈希。明确的动作音效通过 sfx 另轨混入并记录人声基准哈希与混音参数，不要求新混音等于旧音轨。字幕阶段复制最终采用版本的音轨。不自动加音乐。
- 默认竖屏 1080×1920；明确要求横屏才制作横屏。已有确认的基准沿用规格，改画幅时先建立规范化新基准，不直接裁掉主体。
- Remotion 按共同 beat_id、粗剪版本和触发时间插入，支持 fullscreen 和透明 overlay；模板文字不等于字幕。浮层由后期适配固定机位，可覆盖肩膀和手，不遮脸；不要求主播让位或为动画重录。使用前读取 references/motion-handoff.md。
- 素材不必全用。内容相同且质量合适时，动效视频优先于重复静态图；不以动效优先为由选内容不匹配的片段。关键观点、转折和结尾适当保留主播。
- 同一素材被多次使用时，须用不同入点、不同裁切范围或不同景别拉开区分，不能让两处插入出现雷同画面。
- 未明确要求不加口播字幕。素材自身文字不等于口播字幕；发现嵌入字幕或水印应说明，不能假装可直接去除。
- 要求字幕时优先检查本地阿里普惠体；确实安装才使用，缺失则说明并询问替代或安装。推荐中等字重、白字黑边、按语义分短句；字号、位置随画幅和素材留白调整，不写死为所有项目的固定值。
- 下载工具、模型或素材需在当前授权范围内，不把历史项目的下载许可带到新项目。

## 审片与交付

粗剪不能只看转写：每个删减连接点检查前后至少 0.5 秒声音，重复单字、轻声、连读和弱字尾重点复听。无法可靠听审时明确列出待用户复核点，不声称已听审。用户反馈“多剪了”时回到原始音频局部修复，不重新自动剪整片。

粗剪分两轮：先去重录和长停顿，再单独检查句内拼接、短气口和句首等待。使用 `scripts/review_cuts.py` 从实际导出文件生成剪口审听包及待审清单，方法见 commands.md。整体转写和计划音频可辅助检查，但不能替代实际导出声音的剪口复核。未听审时交付标为“待试听粗剪”，不得仅凭转写通顺报告“无重复、无缺字”或“全部通过”。

导出后检查实际帧数、完整解码、音画时长、旋转和画面边界；无音效的素材阶段及字幕阶段检查整个音轨哈希；新增动作音效时检查人声来源、混音参数与试听，分别记录。抽查每个素材的入点、中段、出点及所有字幕行宽、缺字和遮挡。动效数字须检查最终落点，不能把动画中的中间数值误认为结论。

做过亮度、对比度、锐化或裁切的派生素材，插入前须与主播基准做曝光比对：逐段抽样统计灰度均值与动态范围，低于主播基准一档以上（画面发闷、细节丢失）或明显过曝都要重调。校正在先量原片黑位与均值，再决定提亮还是压暗；不要凭观感直接给亮度参数，方向错了会把正常素材压暗。

交付当前阶段的视频链接和简短说明，字幕阶段另交 SRT。保留编辑计划和检查报告方便继续修改。程序检查通过不代表语义、口型、字幕同步已被人工确认。
